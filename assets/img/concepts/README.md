# Concept illustrations

Eight hand-drawn SVG mock-ups, made for this site before the apps had been seen
running. They were drawn from each project's README and notes, so they show the
*features* accurately but not the actual interfaces. Every one of them is
wrong on layout, palette and iconography.

They're kept here deliberately, as a design source to go through later. Nothing
on the site references them.

| File | Depicts | Where it diverges from the real app |
|---|---|---|
| `tabilog-dashboard.svg` | Budgets-at-a-glance bars + category donut | Flat grey background; the real app sits on a full-bleed photo backdrop. Blue accent; the real accent follows the currency theme (warm gold for AUD). Invented a Dashboard/Budgets/History bottom bar, the real one is Dashboard/Budgets/Shopping in emoji. |
| `tabilog-wallets.svg` | Per-person wallet cards with currency artwork | Real structure is a white *person* card wrapping tinted *budget* cards, each with an emoji marker (🦘 AUD, 🌸 JPY) and four action buttons. SGD drawn teal; it's actually red. |
| `tabilog-receipts.svg` | Pending-receipts inbox | Real one is a modal, not a full screen. |
| `tabilog-split.svg` | Splitting one receipt across budgets | Real one lives inside the transaction modal behind a checkbox, not as its own screen. |
| `tabilog-dark.svg` | Transaction history, dark mode | Real history is a modal with a spending-per-month chart above a table. |
| `tabilog-export.svg` | PDF report preview + format picker | Never verified against the real export screen. |
| `tabipace-day.svg` | A day timeline with per-activity pacing warnings | The real Days tab is *people-centric*: a verdict banner, then a card per traveller with their specific breaches, then the plan. Coral palette; the app is blue. |
| `tabiplanner-grid.svg` | Month grid with a day-detail list | Closest of the eight in spirit. Real app is a warm cream/navy/rust palette with four view modes (Whole trip / Day by day / One day / Journey), a countdown ring and a natural-language quick-add box. |

The drawing style itself (device framing, muted UI greys, the chart treatments)
may still be worth reusing for diagrams or explanatory graphics, which is why
none of it was thrown away.
